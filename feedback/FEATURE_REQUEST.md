# Feature Request Template

Use this to propose a new workflow, policy, capability, or behavior that doesn't exist yet in 0.1.1-beta.

```
Title:
Skill Version:            0.1.1-beta
Category:                 F10 Feature request
Problem:                  <what you can't do today, or what's awkward>
Proposed behavior:        <what you'd want the agent to do instead>
Example request:          <a natural-language request that should trigger it>
Why it belongs here:      <why this fits Agent OS Skill's scope, not just your project>
Workaround today:         <what you do instead, if anything>
Risk if added:            <any governance/safety risk this might introduce>
Status:                   new
```

Notes:
- A feature request does not automatically get built. Recurring, well-evidenced requests become
  candidates in `CORE_CANDIDATES.md` and are evaluated like any other proposed governance change.
- Requests that are really about a specific host or vendor integration are good candidates for a future
  optional adapter, not a change to the agent-agnostic core Skill (see the root README's "What it does
  NOT do" section).
