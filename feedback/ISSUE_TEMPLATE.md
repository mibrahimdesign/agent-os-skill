# Issue Template

Use this for something that felt wrong, broken, unsafe, or confusing. See `templates/feedback-report.md`
for the field-level definitions used here.

```
Feedback ID:              <leave blank if unknown>
Skill Version:            0.1.2-beta
Environment:              <host type, OS family — no private paths/names>
Model:                    <model family/size or "unknown">
Workflow:                 <which workflow was active, or "unclear/routing itself">
Category:                 <F1-F10, see feedback/README.md>
Severity:                 Low | Medium | High
User goal:
Expected behavior:
Actual behavior:
Reproduction:             <sanitized steps or request text>
Impact:
Suggested improvement:    <optional>
Candidate Core rule:      <optional>
Status:                   new
```

### Simple version (if you don't want to fill the table)
Just answer these four questions in your own words:
1. What were you trying to do?
2. What did you expect?
3. What happened instead?
4. Why does it matter?

Remove any real code, secrets, or private identifiers before submitting.
